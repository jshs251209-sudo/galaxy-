⚙️ 파이프라인 작동 원리

run_project.bat 실행 시, 내부적으로 다음 6단계가 순서대로 수행됩니다.

1

데이터 수집 (data_fetcher.py)

SDSS DR18 SkyServer API에 SQL 쿼리를 보내 은하 10만 개의 원시 관측 데이터를 수집합니다. 이미 데이터가 있으면 건너뜁니다.

2

데이터 처리 (data_processor.py)

색상 지수(g-r, u-g), 집중도(Concentration Index), 표면 밝기, Balmer Decrement를 통한 먼지 소광, BPT 라인 비율, 동역학적 질량 및 암흑물질 비율을 계산합니다.

3

시각화 생성 (plot_generators.py + plot_interactive.py)

16개의 정적 상관 다이어그램(PNG)과 3개의 대화형 HTML 그래프를 자동 생성합니다.

4

머신러닝 분류 (run_ml_pipeline.py)

K-Means 군집화로 은하를 4개 진화 그룹으로 분류하고, Random Forest로 은하 유형(타원/나선) 분류 모델을 학습합니다.

5

요약 & 대시보드 갱신

최종 마스터 데이터셋의 크기와 저장 위치를 출력합니다.

6

외부 검증 (validation_tool.py)

M82(폭발적 별생성), M87(타원/AGN), M31(나선) 등 실제 유명 은하의 관측값과 비교하여 분석 결과의 타당성을 검증합니다.

❓ 자주 묻는 질문 (FAQ)

문제가 생겼을 때 아래를 먼저 확인해 보세요.

Python이 설치되어 있지 않거나, 환경 변수(PATH)에 등록되지 않은 경우입니다.
python.org에서 Python 3.12 이상을 설치하고, 설치 시 "Add Python to PATH" 체크박스를 반드시 선택해 주세요.
run_project.bat을 실행한 후 나타나는 검은색 터미널 창이 아직 살아있는지 확인하세요.
터미널을 닫으면 서버도 종료됩니다. bat 파일을 다시 실행해 주세요.
네! output/plots/interactive/ 폴더 안의 HTML 파일을 직접 더블클릭하시면 브라우저에서 바로 열립니다.
이 페이지의 인터랙티브 그래프 섹션에서도 직접 링크를 클릭하여 열 수 있습니다.
data/raw/sdss_100k_raw.csv 파일을 삭제한 후 bat 파일을 다시 실행하면, SDSS에서 최신 데이터를 다시 받아옵니다. (인터넷 속도에 따라 5~15분 소요)
config.py 파일을 열어 EXPORT_EXCEL = False를 EXPORT_EXCEL = True로 변경한 후 파이프라인을 재실행하세요.
약 10만 행의 Excel 변환에는 다소 시간이 걸릴 수 있습니다.
Streamlit이 설치되어 있지 않을 수 있습니다. 터미널에서 pip install streamlit을 실행한 후 다시 시도하세요.
(Streamlit은 선택 사항이므로, 없어도 나머지 기능은 모두 정상 작동합니다.)
