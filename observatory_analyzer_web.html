■ 은하 진화 지수 (GEI v3) 수식 — 우리가 분석한 변수만 사용 (방출선 광도 추가)
GEI = 0.26·S_mass + 0.28·S_quench + 0.19·S_DM + 0.27·S_line (말름퀴스트 부피제한 보정 후 PCA 가중치)
• S_mass = (log M* − 7.5)/4.3 · S_quench = (−8.8 − log sSFR)/3.4 · S_DM = (log M_DM − 8.0)/4.5
• S_line = 0.50·S_Hα + 0.30·S_[SII] + 0.20·S_[OIII] (우리가 분석한 Hα·[S II] 6717·[O III] 광도 소광/이온화 지수)
• 1단계 (0.00~0.28): 원시 폭발적 별 생성기 (가스 분율 ↑ · sSFR ↑ · u-r < 1.4)
• 2단계 (0.28~0.46): 초기 은하 원반 성장기 (나선팔 원반 확장 · 주계열 상단 별생성 활발)
• 3단계 (0.46~0.64): 성숙 나선 구조 안정기 (원반과 팽대부 공존 · SFR, 가스유입 평형)
• 4단계 (0.64~0.78): 별 생성 감쇠기 (차가운 가스 고갈 시작 · 중심 팽대부 비대 · 별 생성 급감)
